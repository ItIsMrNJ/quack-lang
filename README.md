### Quack is the programming language developed for the GoldDuck Engine. 🦆

## Quick Start

Compile:
```bash
g++ -std=c++17 -o quack quack.cpp
```

Run a script:
```bash
quack script.gde
```

Example `script.gde`:
```
let name = "GoldDuck";
quack("Hello, " + name + "!");
```
